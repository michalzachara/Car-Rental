# Car Rental app

---

## Installation

Clone the repository and navigate to the main directory:

```bash
git clone https://github.com/michalzachara/Car-Rental
cd Car-Rental
```

Create a `.env` file in the backend folder:

```env
MONGO_URI=<your_mongo_uri>
PORT=3000

```

---

## Development Setup

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
